# coding-agent

#### Description
Kung Fu Coding 是一款专为 DeepSeek 打造的本地 AI 编程助手：原生支持 deepseek-flash / deepseek-v4-pro，深度集成思维链实时展示。内置 Agent 循环，可调用 Python、终端、文件、数据库等工具，Plan / Ask / Agent 三档权限，兼具 Token 监控、会话历史与检查点回滚，一条 python app.py 即可启动
