Welcome to Kung Fu Whale

Your DeepSeek coding assistant

Chat, write, debug and refactor code — with live reasoning and an autonomous agent.

1 · Connect your DeepSeek API key

Open Settings (⚙) in the top bar, paste your DeepSeek API key, then choose a model and a thinking level. The key stays on your machine.

2 · Choose a working folder

Use the left panel to type a folder path or click “Choose folder…”. The agent reads and edits files inside it — nothing outside.

3 · Pick a permission mode

  • Plan — read-only exploration and planning.
  • Ask — the agent asks before writing files or running commands.
  • Agent — full auto-approve; runs everything automatically.

4 · Key features

  • Streaming answers with live token speed and average TPS.
  • Drag, paste or pick files (images, PDF, Excel, Word) to attach them.
  • Checkpoints let you snapshot and restore your folder.
  • A built-in terminal, Python runner and database viewer.
  • Switch the UI between English and 中文 anytime.
